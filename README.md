
# DermaPura Cosméticos

Projeto desenvolvido para o LAB11 – Projeto Cloud, da disciplina de DevOps.

## Sobre o projeto

A DermaPura Cosméticos é uma empresa fictícia do setor de cosméticos e higiene pessoal. O projeto consiste na publicação de uma One-Page utilizando serviços de computação em nuvem da AWS.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- AWS EC2
- GitHub Actions
- Docker

## Funcionalidades

- Apresentação institucional;
- Seção de qualidade e conformidade regulatória;
- Informações sobre fábrica inteligente;
- Identificação da instância que hospeda a aplicação;
- Contador de tempo de execução.

## Objetivo

Implementar uma infraestrutura em nuvem para hospedagem da aplicação, utilizando práticas de CI/CD e conteinerização com Docker.
